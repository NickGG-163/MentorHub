Название учебного проекта:
MentorHub
Version: 0.1"

Описание:
Task-tracker

Цель:
Практика для собеседований и практика для "потрогать технологии руками"

Требования к окружению:
Python 3.13.7

Последовательность действий от клонированного репозитория до запуска:
python3 -m venv .venv
source .venv/bin/activate
python main.py

Возможности:
- создание целей;
- добавление задач;
- отметка выполнения;
- расчёт прогресса;
- сохранение состояния в JSON.
